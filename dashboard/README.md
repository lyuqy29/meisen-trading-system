# 溜溜交易手册

把 `liuliu-trading-system` 技能（源自量价时空交易方法论）里的文字体系，
变成一个能点、能看、能给结论的本地产品。

```bash
cd dashboard                            # 本地工作区里是 tools/dashboard
bash start.sh                           # 默认 http://127.0.0.1:8777
PORT=9000 bash start.sh
```

启动后直接用浏览器打开地址。也可以深链到某只票或某个页签：

- `http://127.0.0.1:8777/?code=600519`
- `http://127.0.0.1:8777/?tab=watchlist`
- `http://127.0.0.1:8777/?tab=positions`
- `http://127.0.0.1:8777/?tab=system`

## 四个页面

| 页面 | 作用 |
|---|---|
| **单票分析** | 输入代码 → 拉日 K → 算均线带/BIAS/异动 → 九模型打分 → 出交易计划（买点/仓位/止损/止盈/失效条件） |
| **自选对比** | 自选池横向排队，按「可交易性 > 模型等级 > 得分 > 活跃度」排序，用于同板块选强 |
| **持仓管理** | 记录成本价，**开仓即锁定止损位**，之后每天对照离场纪律：止损触发 / 破位清仓 / 减仓预警 / 止盈区 / 模型转弱 |
| **体系说明书** | 位置判定、均线带、三类买卖点、九模型速查、双十法则与止损纪律 |

### 持仓管理的口径

建仓时把「结构位与 −12% 静态止损取先到者」**落库锁定**，之后不再随行情漂移——这是 `risk.md`
里「开仓前必须写明止损位」的执行版。离场判定按优先级：

| 优先级 | 信号 | 触发条件 | 动作 |
|---|---|---|---|
| 1 | 止损触发 | 现价 ≤ 锁定的止损位 | 无条件离场 |
| 2 | 破位清仓 | 现价 < MA55 | 清仓 |
| 3 | 减仓预警 | 现价 < MA13 | 减仓 |
| 4 | 止盈区 | BIAS60 ≥ +30% | 分批止盈 |
| 5 | 模型转弱 | 当前无模型命中 | 按失效条件复核 |

两个额外保护：单票仓位 > 20% 标红（双十法则上限）；建仓时若结构位高于成本价，
说明模型在开仓那一刻就失效了，止损位会自动退化为 −12% 并按 ⚠ 提示。

## 判定逻辑（与技能口径一致）

1. **位置第一**：距 250 日高点跌幅 ≥40% → 低位；距低点涨幅 ≥100% 且 BIAS60 >30% → 高位；其余中继。
2. **六要素打分**：异动价 / 异动量 / 均线结构 / 位置 / 时间 / 无失效。6/6 标准版，4—5 弱化版，≤3 不成立。
3. **仓位分级**：A 级试仓 6%、上限 20%；B 级试仓 3%、上限 10%；C 级 0%。建仓节奏 1/3 → 1/3 → 1/3。
4. **止损**：模型结构位与 −12% 静态止损**取先到者**；结构位高于现价 → 模型已被跌破，直接规避。
5. **止盈**：MA60 正乖离 +30% / +50% / +100% 三档价格。

## 数据来源与局限

- 行情：腾讯 `web.ifzq.gtimg.cn` 前复权日 K（近 320 根），本地拉取、90 秒内存缓存，不落库。
- 检测是**机械口径**：只覆盖可量化的部分。**筹码分布、题材级别、大盘环境拿不到**，⑧ 的「双峰真空带」会标成缺料项，需要人工核对。
- 东财接口在本机不稳定，因此只走腾讯；如要换源，改 `market.py` 的 `fetch()`。

## 文件

```
dashboard/
├── market.py     # 行情拉取 + 均线带 / BIAS / 异动事件
├── models.py     # 九大模型检测、6 要素打分、仓位与止损计划
├── server.py     # 本地 HTTP + JSON API（无第三方依赖）
├── start.sh      # 一键启动
├── web/          # 单页应用（原生 JS + Canvas，无 CDN）
└── data/         # 自选池 watchlist.json
```

API：`GET /api/analyze?code=`、`GET /api/compare?codes=`、`GET/POST /api/watchlist`、`GET/POST /api/positions`、`GET /api/health`。

## 与技能的关系

技能（仓库根目录的 `SKILL.md`；本地装在 `.dsh/skills/liuliu-trading-system/`）是**体系原文**，负责讲清楚「为什么」；
本手册是**执行层**，负责把同一套口径算出来、打分、给出可填的交易计划。两者共享同一组阈值。

> 这是课程体系的纪律化工具，不是投资建议。模型不是 100% 胜率，位置错了形态再像也不算模型。
