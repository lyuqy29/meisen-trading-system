一、先定位置，再谈形态

  • 低位：距 250 日最高点跌幅 ≥ 40%，或长期横盘平台下沿 → 反转区
  • 中继：上升趋势中回踩中期均线组 → 加仓区
  • 高位：距 250 日最低点涨幅 ≥ 100% 且 BIAS60 > 30% → 出货风险

二、移动平均带：战略层

  • 短期组 5 / 8 / 13，中期组 55 / 60 / 65，中枢 60 日线
  • 斜率 30—45° 健康，60—80° 加速，走平转弱
排列判定口径含义操作
多头排列短期组 3 根全部在中期组之上（完全分层）短期成本高于中期成本，回踩有承接持股区 / 顺势
空头排列短期组 3 根全部在中期组之下（完全分层）中期套牢盘压制，反弹即解套抛压远离，不接反弹
缠绕 / 粘合两组重叠或穿插，未形成完整上下分层筹码换手，方向尚未选择观察区，不操作

判定用严格口径：短期组只要有一根还落在中期组区间内，就归「缠绕/粘合」，不算多头排列。

  • 排列是快照，不是结论：一根大阳或大阴就能改写，必须连看斜率
  • 必须叠加位置：低位多头 = 反转试仓；高位多头 = 只减不加；低位空头 = 末段等企稳；高位空头 = 破位清仓
  • 缠绕 ≠ 粘合：缠绕是带幅仍宽的来回拉锯；粘合是六根均线挤到一起，属变盘前夜——等一根放量 K 线选方向
  • 它是「均线结构」这一票：多头给分、缠绕降级（多出弱化版）、空头基本不给分，模型形态再像也判失效

BIAS60 =（收盘 − MA60）/ MA60。负乖离 −20%～−30% 为第一类买点区；正乖离 +30%/+50%/+100% 分三级止盈。

三、三类买点与三类卖点

买点触发动作
乖离买点（一类）加速下跌、BIAS60 进入 −20%～−30%试仓
突破买点（二类）放量中阳突破中期均线组加仓
回踩买点（三类）突破后回踩中期组不破、再放量加仓

卖点：乖离极值分批 / 跌破短期组减仓 / 放量中阴跌破中期组清仓。三类买点不必全出现，出现越多仓位越重。

四、九大模型速查

模型核心最佳位置
① 上影反攻涨停破板长上影洗盘 + 天量 + 回踩中阳底部/顶部区间
② n式倍量双涨停两次倍量涨停夹回撤，n 字对称下跌末端
③ 串阳爬坡>7 连阳小步 + 末端大阳换手转势初期
④ 探路尖兵涨停进密集区 + 巨量 + 缩量修正二波中继/突破前
⑤ 极值反转跌停与涨停同位置对称下跌末端
⑥ 一柱擎天倍量涨停后沿短期组 30—45° 推进趋势/题材龙头
⑦ 仙人指路3 个月平台 + 历史级放量涨停突破大级别底部
⑧ 筹码乖离修复负乖离 ≥30% + 双峰真空带中期下跌末端
⑨ 真空反转平台平台破位跌不动 + 跳空涨停，缺口不补下跌中继末端

五、仓位与止损（risk）

  • 双十法则：散户单票 ≤ 20%，组合 3—5 个板块，100 万以内持 3—5 只
  • 分级：A 级三要素齐备+主线+多头+共振；B 级部分满足；C 级只观察
  • 建仓节奏：试仓 1/3 → 突破加 1/3 → 回踩确认加 1/3
  • 止损：结构位（模型低点/缺口/平台/均线）与 −12% 静态止损取先到者
  • 禁止：亏损摊平、无止损下单、用「再等等」代替纪律

六、六项要素打分口径

每个模型固定核对 6 项：异动价 / 异动量 / 均线结构 / 位置 / 时间 / 无失效。

  • 6/6 → 标准版，可按买点建仓
  • 4—5 → 弱化版，降仓或等确认
  • ≤3 → 不成立，不做

本手册是机械口径实现：只覆盖可量化部分。筹码分布、题材级别、大盘环境需人工补充。
