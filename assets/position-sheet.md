## 三、仓位规则检查

- [ ] 持仓只数 ≤ 上限（100 万内 3 只，100–1000 万 5 只）
- [ ] 没有绿盘标的（或已在处理中）
- [ ] 每只票的定量止损额已确认（手笔 × 15%）
- [ ] 加仓只加在盈利标的上
- [ ] 微利标的已优先减仓（成本线 = 心态水平线）

## 四、减仓优先级（大盘转弱时按顺序）

1. 微弱盈利的标的（保住红盘）
2. 小亏但未到定量止损额的标的
3. 跟风股 / 后排标的
4. 最后才是龙头（且需板块进入回落段）
