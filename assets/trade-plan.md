# 交易计划模板（梅森体系）

> 用法：每个标的、每一笔交易前填写。**填不出来的格子，就是你不能买这只票的原因。**

## 一、时机层（先占时机）

| 项 | 内容 |
|---|---|
| 大盘状态 | 上涨 / 下跌 / 震荡（选一个） |
| 大盘势能 | 正在蓄势 / 已被消耗 / 中性 |
| 本笔交易取的是什么势 | 双跌反弹势能 / 当弱不弱 / 趋势回踩 / 双涨延续（只能短） |
| 时机结论 | 可以出手 / 等 / 不出手 |

## 二、方向层（后占逻辑）

| 项 | 内容 |
|---|---|
| 所属主线/题材 | |
| 主线四特征自检 | 持续性 ☐ 波动性 ☐ 见顶迹象 ☐ 整体性 ☐ |
| 板块所处阶段 | 主升段 / 盘整段 / 回落段 |
| 个股所处梯队 | 第一梯队（龙头）/ 第二梯队 / 跟风 |
| BEAT 自检（可选） | 故事 ☐ 业绩 ☐ 共识 ☐ 标的 ☐ |

## 三、位置层（最后占位置）

| 项 | 内容 |
|---|---|
| 买点类型 | ①双杀 ②当弱不弱 ③趋势回踩 ④形态买点（W底/圆弧底/均线粘合） |
| 均线状态 | 5/10/20 朝上 / 缠绕 / 朝下 |
| 触发价/触发条件 | |
| 周线级别确认 | 是 / 否（不确认则只看短线） |

## 四、仓位与风险（撩妹法则 + 量化）

| 项 | 内容 |
|---|---|
| 当前持仓只数 / 上限 | 　/　（100万内≤3只，100-1000万≤5只） |
| 本笔性质 | 试仓 / 加仓（必须加在盈利标的上）/ 减仓 |
| 试仓比例 | % |
| 定线止损位 | -15%（或自定义，写在买入前） |
| 定量止损额 | 手笔 × 15% = 　　元 |
| 止损触发条件 | 二者先到者 |
| 最大可承受亏损 | 　　元（占账户 %） |

## 五、退出计划（先想好怎么走）

| 情形 | 动作 |
|---|---|
| 涨到 +__% 或 出现滞涨/背离 | 减仓 __% 锁利 |
| 跌破 __ 均线（5/10/20） | 减仓 __% |
| 跌破成本线前 | 必须减仓，维护全红 |
| 触及止损 | 无条件清仓，不商量 |
| 板块进入回落段 | 清仓，不再看 |

## 六、层次感自检（冲突时按顺序）

1. 这笔操作违反纪律吗？→ 违反就停。
2. 不处理会破坏账户全红吗？→ 会就先减仓。
3. 我的主观看法是否在推翻上面两条？→ 是就放弃主观。

## 七、复盘栏（平仓后填写）

| 项 | 内容 |
|---|---|
| 实际结果 | 盈 / 亏 / 平，收益率 |
| 买点是否成立 | 是 / 否，为什么 |
| 纪律是否执行 | 是 / 否（没执行的话，是哪一个优先级冲突） |
| 下次改进的一条 | |
