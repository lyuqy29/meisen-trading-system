# 复盘模板（梅森体系）

> 每笔交易平仓后 24 小时内填完。复盘不是写感想，是**定位是哪一层出了问题**。

## 一、交易基本信息

| 项 | 内容 |
|---|---|
| 标的 / 板块 | |
| 买入日期 / 卖出日期 | |
| 买点类型 | 双杀 / 当弱不弱 / 趋势回踩 / 形态 / 其他 |
| 当时大盘状态 | 上涨 / 下跌 / 震荡 |
| 当时板块阶段 | 主升 / 盘整 / 回落 |
| 仓位（试仓/加仓/满仓） | |
| 结果 | 盈 __% / 亏 __% |

## 二、四层归因（找到真正的错误层）

### 1. 时机层（大盘）
- [ ] 买入时大盘是否处在我体系允许出手的位置？
- [ ] 我买的是双跌/当弱不弱，还是双涨追高？
- 结论：□ 时机对 □ 时机错

### 2. 方向层（主线/题材）
- [ ] 是主线/热点吗？板块处于哪一段？
- [ ] 买的是龙头还是跟风？
- 结论：□ 方向对 □ 方向错

### 3. 位置层（买点/均线/图形）
- [ ] 买点成立吗？事后看是标准形态还是勉强凑的？
- [ ] 均线当时是朝上/缠绕/朝下？
- 结论：□ 位置对 □ 位置错

### 4. 执行层（纪律/仓位/心态）
- [ ] 有没有按计划止损？（没止损的话，卡在哪个层次感冲突）
- [ ] 有没有在亏损仓位上加仓？
- [ ] 有没有出现「大赚变小赚/亏损」却没减仓？
- 结论：□ 执行对 □ 执行错

## 三、最关键的一条教训

> 只写一条，必须是**可执行的动作**（例如：「跌破 5 日线当天必须减半仓」，而不是「要更谨慎」）。

## 四、如果重来一次

- 同一标的、同一时点，按体系应该怎么做？
- 这个做法和当时的操作差在哪一步？

## 五、错误类型标签（便于统计）

| 标签 | 含义 |
|---|---|
| `时机-追高` | 在双涨/消息高潮买入 |
| `时机-逆势` | 大盘下跌期强行做多 |
| `位置-接刀` | 趋势朝下时抄底/补仓 |
| `纪律-不止损` | 触及止损线未执行 |
| `纪律-亏损加仓` | 扭亏交易 |
| `仓位-超限` | 持仓只数或单票超过上限 |
| `仓位-大赚变小赚` | 未在成本线上方减仓 |
| `方向-跟风当龙头` | 在盘整/回落段买后排 |

> 统计三个月后，出现频次最高的那个标签，就是你当前最该改的一条。
