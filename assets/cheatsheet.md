# 梅森体系 · 一页速查卡

> 打印/贴在屏幕旁。全部规则来自 19 讲课程 + 官方框架图，详细出处见各 reference 文件。

## 一句话

**先占时机，后占逻辑，最后占位置。** 时机决定赚不赚，逻辑决定赚多少，位置决定亏多少。

## 下单五问（按顺序，任何一问不过就放弃）

1. **时机**：大盘在下跌后吗？我取的是哪一段势能？（双跌 / 当弱不弱 / 回踩 / 双涨延续只做短）
2. **方向**：是主线/题材？板块在主升/盘整/回落？我是龙头还是跟风？消息落在哪个象限？
3. **位置**：五大买点命中哪一个？5/10/20 均线是朝上/缠绕/朝下？周线确认了吗？
4. **仓位**：这是试仓（1/6~1/5）还是盈利加仓？持仓超上限了吗？
5. **风险**：定线止损 -15%？定量止损 = 手笔×15%？最大亏损可承受？

## 买点速记

| 买点 | 条件 | 适用 |
|---|---|---|
| 双杀 | 大盘跌 + 个股跌（**大盘必须跌**） | 建仓/长线最优 |
| 当弱不弱 | 大盘跌 + 个股不跌/横盘 | 同样好，常直接新高 |
| 回踩 | 上升趋势中的小调整 | 波段 |
| 形态 | W底 / 圆弧底 / 均线粘合后发散 | 中继 |
| 抄底 | 三天不新低（低确定）/ 均线联合朝上（高确定） | 超短 / 波段 |

## 卖点速记

- 双涨（势能耗尽）→ 只能做短期，先撤
- 当强不强（大盘涨它不涨）→ 卖
- 板块进入回落段 → 清，不再看
- 主线从「面→线→点」收敛 → 无差别减仓
- 均线朝下（中线必须减仓）

## 纪律三条（优先级）

1. **纪律 > 仓位管理 > 主观认知**（冲突时向上取）
2. 亏损标的一律**标准化处理**：不问基本面、只看趋势、触及额度无条件走
3. **永远不要从大赚到亏损**：跌破成本线前必须减仓

## 仓位

- 只数：100 万内 ≤3 只，100–1000 万 ≤5 只（个人极限 5 只）
- 加仓只加**盈利**标的；减仓先减**微利**和**小亏未止损**的
- 目标：**账户全红**（成本线 = 心态水平线）

## 亏损时的四个禁止

❌ 亏损加仓 / ❌ 亏损时问基本面 / ❌ 死扛不设限 / ❌ 两边摇摆

## 每周复盘

1. 这周的交易属于我选定的周期吗？
2. 决策是「概率优先」还是「赔率幻觉」？
3. 有没有在亏损仓位里做主观决策？

> 赚钱是迎合了市场的奖励，亏钱是对市场不够迎合。
> **少做判断，多卡节奏，只交易看见的东西。**
