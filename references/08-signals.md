# 试错四信号：什么时候真的扣扳机

> 出处：框架图「试错」分支（信号 1–4）+ 第 04 课（取势）、第 12 课（交易看见）。

## 1. 核心心智

- **赚钱是迎合了市场的奖励；亏钱是对市场不够迎合。**
- **交易的本身就是不断用试错来捕捉大行情。**
- **少做判断**：不做「它一定会涨」的预测，而是走完这个流程——
  > **逻辑假设 → 捕捉交易信号 → 交易**
- 你的预期和市场的表达之间，**需要一个信号**。没有信号的预期，只是主观。

## 2. 四个信号（满足越多越可靠）

### 信号 1：顺大势、逆小势——上升趋势中，调整即买入

- 大势（周线/月线/大盘趋势）向上；
- 小势（日线/日内）向下调整；
- 调整结束就是买点。这就是「顺大势、逆小势」。
- 对应买点：`07-buy-points.md` 的回踩买点。

### 信号 2：当强不强，当弱不弱

- **当强不强**：该涨的时候不涨（大盘涨、个股不涨）→ 弱，卖点。
- **当弱不弱**：该跌的时候不跌（大盘跌、个股不跌/横盘）→ 强，买点。
- 这是框架中「中级的确定性」：比均线趋势更高级别的确认。
- 判断时注意**放大视角**：至少用周线级别，不要因为一两天背离就下结论。

### 信号 3：板块集体出现异动

- 不是单只股票异动，而是**板块内多只股票同时异动**（多只涨停、集体放量、同时突破）。
- 意义：说明是资金层面的共识，不是个股行为。
- 这是「主线确认」的盘面证据（见 `02-mainline.md` 的「整体性」）。

### 信号 4：技术上出现明显的抵抗

- 形态层面：长下影、下影线密集、跌不动的缩量、关键均线/前低处的反复支撑、W 底或圆弧底。
- 意义：空头力量衰竭的证据，是「试错成本最低」的位置。

## 3. 试错的成本结构

- 试错不是乱试，是**用固定的小成本，换一个大概率的展开**。
- 每次试错的成本 = 试仓比例 × 止损幅度（见 `04-stop-loss.md`）。
- **让试错走进自己的节奏**：固定信号、固定成本、固定止损，重复执行，不因单次结果修改规则。

## 4. 试错流程（贴在屏幕上的版本）

```
① 大势向上吗？（大盘趋势 / 周线）—— 否 → 不出手
② 主线明确吗？（板块整体性 + 持续性）—— 否 → 只做短线
③ 出现四个信号中的至少 2 个吗？—— 否 → 等
④ 试仓（小）→ 设定量止损
⑤ 盈利 → 加仓（在盈利基础上，波段视角）
⑥ 亏损 → 触及止损线无条件走人
```

## 5. 常见错误

| 错误 | 结果 |
|---|---|
| 没有信号就买（凭「我觉得」） | 试错变成了赌博 |
| 信号出现但大势向下 | 逆势，大概率被埋 |
| 试错仓位过重 | 一次错误就伤筋动骨，失去继续试错的资格 |
| 试错成功后不敢加仓 | 赚小钱，违背撩妹法则 |
| 试错失败后立刻反向做 | 在噪音里反复被打 |
