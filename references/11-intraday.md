# 做T与日内买卖点（含做T式加仓）

> 出处：第 13 课《做T与日内买卖点》、第 14 课《做T与日内买卖点（2）如何加仓》。
> 说明：本课原本是给交易团队（T+0 部门）的内部培训，后整理为体系内容。

## 1. 什么是做T

- **做T = T+0**：在**有底仓**的前提下，当天买入卖出，**收盘后底仓数量不变**，从波动里赚差价。
- 两种方向：
  - **正T（做多T）**：先买后卖（当天低点买、反弹卖）；
  - **反T**：先卖后买（当天高点卖、回落买回）。
- **建议只做正T**：统计下来做得好的交易员绝大多数做正T——因为你本来就看好这只股票，先买后卖内心踏实；先卖后买与最初心态相违背，容易做错。

## 2. 做T的四种图形（买卖点高度对称）

> 核心认知：**买卖点在技术上是高度对称的**——把图形倒过来，就是反向的对应买卖点。

### 2.1 联动买卖点（板块联动）

- 适用：**热门板块中的跟风标的**（龙头不适合做T，波动由它自己主导）。
- 方法：
  1. 把该板块的**龙头与跟风标的**放在一起看；
  2. 龙头涨停的那一瞬间 → 跟风股出现**快速买点**（会跟风上拉）；
  3. 龙头跌停/跳水 → 跟风股**卖点**（会跟着跳水）。
- 例子（课程原例）：券商板块，龙头中银证券 11:18 涨停 → 同花顺同步快速买点；阿里概念龙头跌停 → 跟风股立刻卖。
- 局限：大多数股票不在热点上，所以不算最常用。

### 2.2 均线理论（分时均线）

- 强势股：分时线持续在均线上方运行，**回踩均线 = 买点**（均线形成支撑）。
- 弱势股：分时线在均线下方，**反抽均线 = 卖点**（均线形成压力）。
- **转换**：一旦强势突破均线并在上方运行，之后再回踩均线，原来的压力就变成支撑 → 买点。
- 局限：分时与均线经常缠绕，缠绕时**不要用**这个方法；只适合极强的或极弱的股票。

### 2.3 支撑压力（M头 / W底）

- 分时出现一个高点后回落，**再次冲击该高点冲不上去 → 卖点（M头）**。
- 分时出现一个低点后反弹，**再次回踩该低点跌不破 → 买点（W底）**。
- 同样适用于日 K 线。
- 用法定位：做T时确定性一般；但作为**日内的试错买点/卖出点**很有效。

### 2.4 急涨急跌（交易员最常用）

- **急跌买点**：日内出现**放量的急跌**（有恐慌盘、非理性出货）→ 之后必有反抽 → 短期买点。
  - 关键条件：**最好与指数同步杀跌**（双跌）。如果大盘在涨、个股独立急杀，买点不确认。
  - 原理：大盘杀跌后会反弹，带着势能推个股（`03-timing.md` 的取势）。
- **急涨卖点**：日内放量快速拉升（一波拉 6–7 个点）→ 容易出卖点；**拉得越高，交易空间越大**。
- **委托报价技巧**（重要）：
  - 盯分时**委托报价**：某个价格**重复出现**，说明那里有支撑/压力 → 果断进场；
  - **顶着下杀买、顶着上涨卖**，不要等分时拐头才动手；
  - 需要敏锐度，而敏锐度来自盯报价盘的重复价位。
- 结论：**急跌 + 正T** 是最常见的做T方式（符合人性）；急涨做反T较少（怕拉涨停卖飞）。

## 3. 做T式加仓（第 14 课核心）

### 3.1 定义

当天做多T（正T），如果**盈利较多（最好 2% 以上）**，就把当天买入的那部分**不平掉、留作加仓**——这叫**做T式加仓**。
这与撩妹法则完美搭配：**顺大势、逆小势**（顺上升趋势，逆日内小调整）。

### 3.2 先决条件

1. **个股 K 线趋势向上**（上升趋势或短期看涨）——下跌趋势不能做T式加仓；
2. **当天必须做T成功（有盈利）**，2% 以上最好——这部分盈利就是**次日安全带**；
3. **大盘早盘杀跌是关键先决条件**（最好低开下杀）。

### 3.3 最佳时机：开盘半小时内的「双杀」

- 时间：开盘半小时（成交活跃、预期偏差大，隔夜利空容易低开）。
- 形态：**大盘低开下杀 + 个股同步下杀**（双跌），个股跌 2–3%、3–5% 最舒服。
- 原理：大盘杀跌是在压弹簧，压得越紧反弹势能越大；个股被带下来后，反弹时会被推上去。
- **大盘杀跌是必要条件，个股杀不杀关系不大**（个股不跌=当弱不弱，同样能取势）。

### 3.4 三种错误做法（务必避免）

| 错误 | 为什么错 |
|---|---|
| **大盘高开、没有明显下杀，个股独立杀跌** 去做多T | 个股独立杀跌说明它自身有基本面问题；拿不到大盘的反弹势能 |
| **当天做T没赚钱（亏损或持平）不平仓，硬当加仓** | 违背初心与纪律：你原本的计划是「T成功才加仓」，T失败就该平掉 |
| **做T变成做股票**（上午买下午卖、隔夜持有） | 超过 3 分钟不可控性就上升，本质已不是做T，而是赌博 |

> 铁律：**当日T成，当加仓；当日T错，也要平仓。** 只有 T 成功了才留到隔夜。

### 3.5 做T式加仓口诀

```
上升趋势做多T，下跌趋势不做多T
早盘杀跌好做T，水下交易空间大
大盘个股双杀T，独立杀跌勿多T
当日T成当加仓，当日T错也平仓
图形压力还亏钱，这种T就不该做
```

## 4. 做T的纪律与前提

1. **一笔T不超过 3 分钟**（交易员标准，常常半分钟结束）——超过就变成做股票了。
2. **少做T**：没有约束的人很容易把做T做成深套（T亏了不卖，收盘变成加仓）。
3. **专业做T的收益预期**：1000 万账户，一个月稳定 T 出约 **5%**，不是靠做T赚大钱。
4. **只做有波动的股票**：日内波动只有 2–3 个点、成交量又小的股票，**没有做T空间**。
5. 做T图形与日内买卖点是**通用**的：你试错买入、卖出时同样可以用这四种图形——它们本质上是在寻找日内的低点和高点。
6. 与日线趋势融会贯通：例如「偏离 5 日线太远一定要回踩 5 日线」就是同一逻辑在日线上的体现。
