# 自检清单（下单前 / 持仓中 / 平仓后）

## 一、下单前（缺一项就不买）

### 时机（第 01/04 课）
- [ ] 大盘处于上涨 / 下跌 / 震荡？我这一笔是不是在「大盘下跌后」出手？
- [ ] 我能说清楚这笔交易**取的是哪一段大盘势能**吗？（双跌/当弱不弱/回踩/双涨延续）
- [ ] 如果大盘在涨且已经涨了一段 → 我是不是只想做**短期**？

### 方向（第 12/17 课）
- [ ] 是不是主线/热点方向？板块处在**主升段 / 盘整段 / 回落段**？
- [ ] 我买的是**龙头**还是**跟风**？（跟风股在盘整段就要走）
- [ ] BEAT 四要素成立几条？（B 故事 / E 业绩 / A 共识 / T 标的）
- [ ] 这个消息是不是「一日游」风险？有没有等**超预期**的确认？

### 位置（第 11/12 课）
- [ ] 命中哪一类买点？（双杀 / 当弱不弱 / 回踩 / W底/圆弧底/均线粘合）
- [ ] 均线状态：5/10/20 朝上 / 缠绕 / 朝下？（朝下不做，缠绕不重仓）
- [ ] 有没有放大到**周线级别**确认过？

### 风险（第 02/03/06 课）
- [ ] 定线止损位写下来了吗？（-15% 或自定义）
- [ ] 定量止损额算了吗？（手笔 × 15%）
- [ ] 这笔最大亏损占账户多少 %？能不能承受？
- [ ] 持仓只数超过上限了吗？（100 万内 ≤3 只，100–1000 万 ≤5 只）
- [ ] 这是**试仓**还是**加仓**？加仓的话，加的是盈利标的吗？
- [ ] 层次感自检：这笔操作有没有和纪律冲突？冲突时我放弃主观了吗？

## 二、持仓中（每天收盘 5 分钟）

- [ ] 账户是否仍然**全红**？（有绿盘 → 处理它，不要养着）
- [ ] 有没有标的正从「大赚」往成本线滑落？（必须在跌破成本前减仓）
- [ ] 主线/板块是否进入**盘整段或回落段**？（进入就减）
- [ ] 大盘状态有没有变化？（下跌 → 降仓位，先减微利和小亏未止损的）
- [ ] 有没有出现「当强不强」的持仓？（大盘涨它不涨 → 卖点）
- [ ] 今天的做T是否遵守了「当日T成当加仓，当日T错也平仓」？

## 三、平仓后（复盘三问）

1. **买点是否成立？**（当时是双杀/当弱不弱/回踩/形态中的哪一种，事后看成立吗）
2. **纪律是否执行？**（止损、加减仓顺序、持仓上限；没执行的话是哪个优先级冲突）
3. **下次改进的一条是什么？**（只写一条，写具体动作，不写「要更谨慎」）

## 四、红黄牌机制（自我约束）

| 信号 | 动作 |
|---|---|
| 连续 3 笔亏损 | 降低交易频率，仓位减半，只做双杀买点 |
| 单月回撤 > 10% | 停止开新仓，只处理存量持仓 |
| 出现「从大赚到亏损」 | 强制复盘：为什么没在成本线上方减仓 |
| 持仓超过上限 / 出现深套 | 强制减仓到全红或止损 |
| 违反纪律一次 | 记录在案，当月禁止加仓新方向 |

> 纪律是投资过程中的宪法，没得商量。
