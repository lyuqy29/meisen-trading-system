# 梅森投资框架总纲

> 出处：课程官方思维导图《梅森投资框架》（newie/梅森投资框架.png）+ 18 讲系统课。
> 这份文件是体系的「骨架」，其它文件是骨架上的肌肉。做任何分析前先过一遍本文件的分层。

## 0. 一句话体系

**先占时机，后占逻辑，最后占位置。**
时机=市场给不给饭吃；逻辑=主线/题材/业绩成不成立；位置=个股在图上的买点。
三者顺序不可颠倒：**时机对了，逻辑和位置差一点也能赚钱；时机错了，逻辑和位置再好也容易亏钱。**

## 2. 投资哲学（五条底层假设）

1. **万物皆周期**：没有只涨不跌的赛道，也没有永远的低估。周期是仓位与预期的锚。
2. **价值一定会被发现**：价格偏离价值只会迟到、不会缺席，但「被发现」需要催化剂和时间。
3. **流动性溢价**：资金推动的价格里含流动性溢价，流动性收缩时溢价先被抽走。
4. **风险才有收益**：不承担风险就没有超额收益，关键是把风险**定量**（见 `05-position.md` 止损）。
5. **墨菲定律**：如果坏事有可能发生，那么它一定会发生，而且很大可能会造成严重后果。
   → 推论：**任何可能让你大亏的持仓结构，都不允许存在**（不止损、单一重仓、逆势加杠杆）。

## 3. 交易的三个层次

- **交易纪律**：规则先于观点。定线止损、定量止损、非盈利不加仓、错了严格止损。
- **仓位管理**：以**维护账户全红**为目标（不是单笔赚多少）。
- **顺势而为**：大盘趋势良好→考虑做多；大盘趋势不佳→坚持防守。

## 4. 机会的三层（决定你赚的是哪一档钱）

| 层级 | 机会 | 难度 | 收益量级 | 要点 |
|---|---|---|---|---|
| 低级 | 选股 | 低 | 小 | 选对个股，但可能逆着市场 |
| 中级 | 交易市场的选择 | 中 | 中 | 选对指数/板块/风格 |
| 高级 | 把握好时机 | 高 | 大 | 在对的时间做对的方向 |

**绝大多数人死在只做「低级机会」**：埋头做个股，不尊重大盘。

## 5. 主线（本体系的核心研究对象）

**主线的四个特征**
1. **持续性**：主线具有持续性，不会轻易结束——数万亿以上资金共同推动，不容易轻易结束，也不能轻易判断结束。
2. **波动性**：跟随试错波动而波动（日内/日线级别的剧烈震荡是主线的常态）。
3. **见顶**：与市场形成背离（指数新高而主线不新高，或主线内部大面积补涨后滞涨）。
4. **整体性**：呈现出整个面上的上涨（板块内多数股票同向，而非单点龙头独舞）。

**应对主线的调整**
- 大盘趋势良好 → 考虑做多；大盘趋势不佳 → 坚持防守。
- 主线的形成是数万亿以上资金共同推动，**不容易轻易结束，也不能轻易判断结束**。
- **主线节奏与大盘节奏基本一致**：用大盘节奏去校验主线节奏，不要幻想主线能长期独立于大盘。

**从交易预期到交易看见**
> 市场的大主线不是判断出来的，是走出来的。**看见主线，交易主线。**
所以：少做预判，多做验证；预判只用来准备，交易只发生在「看见」之后。

## 6. 寻找确定性（概率思维）

- 没有绝对的确定性，**确定性是概率**。
- **最基础的确定性：均线趋势**（见 `10-ma-trend.md`）。
- **中级的确定性：当强不强，当弱不弱**（该涨不涨=弱，该跌不跌=强，反向信号）。
- **让试错走进自己的节奏**：试错不是乱试，是用固定的小成本、固定的信号，去等一个大概率的展开。

## 7. 价格脱敏 vs 价格锁定

- **大方向看价格锁定**：大级别（周线/月线、产业周期）要盯住关键价格区间，不被噪音干扰。
- **小方向看价格脱敏**：日内、日线级别的波动要「脱敏」，否则会被洗出去。
- **在一个周期中，会出现多次价格脱敏**：一轮主升里会有 N 次让你难受的震荡，每次都以为是顶。

## 8. 科学思维（五种）

- **归纳思维**：从历史相似结构里归纳出可重复的形态（三大买点就是这样来的）。
- **验证思维**：假设→找证据→验证，而不是找理由支持自己的持仓。
- **试错思维**：用小仓位、小止损去「买答案」，而不是一次押注。
- **预演思维（预见）**：提前想好涨了怎么办、跌了怎么办、平了怎么办。
- **博弈思维**：想清楚对手盘是谁、他在什么位置会做什么。

## 9. 交易执行总图

```
时机（大盘/节奏） → 主线（方向） → 位置（三大买点/均线） → 试仓 → 验证 → 加仓 → 止损/止盈
```

- **建仓**：撩妹法则 + 试错思维（见 `06-pickup-law.md`）
- **仓位**：以维护全红为目标，盈利加仓、亏损减仓（见 `05-position.md`）
- **风控**：定线止损 + 定量止损（见 `04-stop-loss.md`）
- **信号**：顺大势逆小势、当强不强当弱不弱、板块集体异动、技术明显抵抗（见 `08-signals.md`）
- **选指数**：上涨期看「灵敏」的指数，下跌期各大指数都要分析
- **抄底**：指数到低位、市场底晚于政策底、时机>个股、底部是试出来的（见 `12-bottom.md`）

## 10. 自我认知（决定你能不能活下来）

- **投资周期可选，但必须匹配自己**：短线（短平快，周期越短操作难度越大、失误越多）、波段（节奏和收益适中，进出场时机较难把握）、中长期（省心省力，选股/持股/买入位置较难把握）、超长期（省心省力，但选股、持股、买入位置、心态考验都最大）。
- **改变投资观念**：**概率比赔率更重要**。
- **改变行为习惯**：盈利加仓、控制风险、维持账户全红。
- **提升能力**：学习、总结、进步。

## 11. 交易的基础（散户的五个致命痛点）

1. 好的股票赚一点就走了，亏的死拿。
2. 跌的不敢加仓，涨的不敢加仓。
3. 缺乏止损意识，容易套牢。
4. 埋头做个股，不尊重大盘。
5. 没有试错思维。

**个股与大盘三态**
- 个股与大盘都涨 → **坚定做多**
- 个股与大盘背离 → **快进快出**
- 个股与大盘都跌 → **空仓**

**市场情绪**：不被市场情绪所影响，要合理利用市场情绪。

## 12. 投资的基本逻辑

- **研究端**：成长性、估值、市场流动性、市场情绪、商业理解力与概率思维。
- **交易端**：尊重趋势；买点——个股与大盘双跌（恐慌买点）；控制心态的交易都是对的；赔率与逆向思维。
- **连接研究和交易两端的是等待。**

## 13. 好赛道六要素（中线/长线选方向的过滤器）

| 要素 | 判断要点 |
|---|---|
| 市场空间 | 天花板够高，能容纳大资金 |
| 周期性 | 弱周期优先，强周期只做景气拐点 |
| 议价能力 | 对上游/下游能否提价、能否占款 |
| 复购频率 | 高频复购 > 一次性消费 |
| 集中度 | **集中度提升是 α 机会**（龙头份额提升） |
| 渗透率 | 渗透率提升带来的股价上涨最暴力，**10%~50% 是甜蜜期** |

## 14. 不可逆的行业趋势（四阶段怎么做）

| 阶段 | 特征 | 打法 |
|---|---|---|
| 导入期 | 炒概念，暴涨暴跌 | 只做情绪，快进快出，不重仓 |
| 成长期 | 炒渗透，趋势性上升通道 | **主战场**：趋势性持有 + 回踩买 |
| 成熟期 | 增速放缓，格局稳定 | 做龙头估值修复/分红 |
| 衰退期 | 需求萎缩 | 不参与 |

## 15. 消息处理（利好四象限）

|  | 影响行业情绪 | 直接影响业绩 |
|---|---|---|
| **少数人知道** | 可买可不买（最多看三天） | **买入价值**（唯一确定买点） |
| **大多数人知道** | **卖出价值**（散户最常踩的坑） | 可买可不买（看持续性） |

**95% 的利好不是用来买股票的**；保鲜期 1–3 天。详见 `13-beat.md`。

## 16. 底部的两个结构

- **三天不新低**（按最低价）：确定性低，适合超短线博反弹。
- **均线联合朝上**（5/10/20 收敛后向上）：确定性较高，适合波段抄优质资产。
- 市场不会 V 型反弹；**底部是试出来的**。详见 `12-bottom.md`。

## 17. 不可复制的竞争优势（护城河五项）

无形资产（品牌、特许经营权、专利）、成本优势、转换成本、网络效应、有效规模。

> 用法：六要素决定「赛道好不好」，护城河决定「谁能在赛道上活到最后」。两者都过，才值得做中长期。
