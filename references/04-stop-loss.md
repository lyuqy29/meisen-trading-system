# 止损：投资的第一课

> 出处：第 02 课《止损》。梅森明确说这是**投资过程当中的第一课，也是最重要的一课**。

## 1. 先修风险敞口

**错误的风险敞口（散户默认状态）**：赚一点点就急着跑，亏了巨大就躺平；跌的敢加仓，涨的不敢加仓。
- 结果：**向上的天花板极低，向下的空间无限** → 长期做下来一定亏。
- 形象说法：**你的风险敞口是朝下开的**。

**正确的风险敞口**：**底线非常低（有止损），天花板没有上限（让利润奔跑）**。
- 巴菲特的说法：斩断亏损，让利润奔跑。多数人做的是反的：**斩断盈利，让亏损奔跑**。

**利弗莫尔的倒金字塔加仓**：先小仓（试探/测试）→ 赚钱了再考虑加仓 → 最后打满。
- 注意：止盈加仓是**多段**的——这一段买入盈利后减仓、留一部分利润在里面，再找时间点进去做多个波段。
- 多数人所谓的「盈利加仓一把亏光」，是在**同一个波段内**刚赚一点就马上加，且是在着急的时间点做的。拉长投资周期看，盈利加仓是可以持续演绎的。

**多赚少亏**：行情好的时候仓位大（多赚），行情不好的时候仓位小（少亏）。

## 2. 两种止损法

### 2.1 定线止损（比例止损）

- 买入前先定：最大亏损比例**不超过 15%–20%**，跌破无条件止损。
- 通行比例：**10% 左右**；梅森个人建议 **15% 左右**。
- 优劣：
  - 缺陷：容易被频繁止损（波动率大的市场里尤其明显）；
  - 优势：不会亏太多；干脆利落。
- **必须提前定线**，不能等亏了再想。

### 2.2 定量止损（金额止损）——梅森推荐

- 设定**任何一个单一标的的最大亏损金额**。
- 计算方式：按你**通常的买入手笔** × 15% 来定量。
  - 例：通常单票买 100 万 → 定量 = **15 万**。
  - 之后无论你买 50 万、100 万还是 200 万，**单票亏损绝不允许超过 15 万**，超了就无条件走人。
- 机构做法：给基金经理下「任何单票亏损不允许超过 1000 万」的硬约束，超了风控组直接强平，**没得商量**。
- 优势：**更灵活**——行情不对可以先减仓（减仓不是止损，是规避短期回撤），把止损线往下拉；亏损标的比例标准化处理，避免在亏损状态下做主观决策。

## 3. 亏损标的一律「标准化处理」

**原则：亏损的标的不适合主观思考。** 亏损状态下人容易不理性，做的判断大多是错的。

机构做法（原话精神）：
1. 一旦标的亏损，**不再看基本面、不再判断趋势、不再自我安慰**；
2. 只看客观趋势：客观趋势向下 → 先减仓，控制风险敞口；
3. 等它跌得差不多了、企稳了 → 再把仓位打进去试错，看能不能救回来（自救）；
4. **过程中始终不允许最大亏损超过定量额度**；
5. 一旦触及定量额度 → **直接止损，非常坚决**。

> 原话比喻：**纪律是投资过程当中的宪法，没得商量的。**

**反例**：房地产/光伏类个股（课程的例子）一路下跌一路加仓——因为「始终觉得是好公司」，最后亏 80%，陷入万劫不复。

## 4. 止损的两个难点

### 难点一：止损后马上反弹

- 心态会崩：「我这个止损到底对不对？」
- 正确认知：**止损后马上反弹，说明你的买点本身有问题，且买点与你的风险偏好不契合**——你应该为那次错误的买点买单。
- 数据观：总结 100 次止损，可能 80% 的止损是对的，只有少数几次止损是错的。**长期坚持止损的整体收益远大于不止损**。
- 连巴菲特也坚决止损，不要用个别案例推翻止损。

### 难点二：好标的不愿意止损

- 逻辑：**投资做的是概率**。你再看好任何标的，都有可能看错。专业人员、明星基金也会套在「好公司」里。
- 真相：**大多数人是在「好标的」里亏大钱的**，因为对好标的不设防。
  - 你觉得它不好 → 最多只考虑投机，亏了会认；
  - 你觉得它很好 → 加仓、扛单 → 亏 60%、80%。
- 结论：**止损对「你认为的好标的」和「你认为的基本面差的标的」必须一视同仁，没有商量。**
- 如果你想投机一个「不好」的标的，也必须带上同样的止损纪律。

## 5. 做好止损的三大好处

1. **亏损有底线**：新手只要每笔都守纪律（15% 止损线 / 15 万止损量），一年下来根本亏不了多少钱——有亏有赚来回抵消，底线远低于其他投资者，从而获得更长的学习时间和空间。
2. **克服畏高心理**：长期的浮亏会形成心理障碍，导致不敢做强势股、错过一倍之后的二倍三倍十倍。**有了止损，高位股和低位股是一样的**（都只亏那么多），畏高心理自然消解，你才有可能去追求「标准逻辑」和「时机」。
3. **才可能做好仓位管理**：不止损 → 账户无法良性筛选（盈利的止盈了，亏损的留着）→ 账户全是亏损标的、随波逐流。
   **止损是仓位管理的第一步**，没有止损就不可能有仓位管理。

## 6. 止损执行清单

- [ ] 买入前写下：定线止损位（-15%）与定量止损额（单票亏损上限 = 手笔 × 15%）
- [ ] 两者哪个先到，按哪个执行
- [ ] 触及定量额度 → **无条件走人，不商量、不侥幸、不找理由**
- [ ] 下跌破位但未触及额度 → 先减仓控制回撤（减仓 ≠ 止损）
- [ ] 企稳后想买回 → 重新按新买点试错，不因为「成本」而拒绝
- [ ] 止损后反弹 → 记录为买点问题，复盘买点，不修改纪律

## 7. 一句话总结

> **止损不是亏损，止损是买「继续留在这个市场里」的期权。**
> 一次侥幸，就容易出大错。
