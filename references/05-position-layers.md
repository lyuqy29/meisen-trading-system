# 层次感：冲突时先拥抱谁

> 出处：第 06 课《建立仓位管理中的层次感》。这是整套体系的「优先级法则」，比任何技巧都更决定生死。

## 1. 什么是层次感

**层次感 = 永远明白什么问题更重要。**
当问题与问题之间产生矛盾时，你知道应该优先拥抱什么。这是**抓大放小**的基础。

- 投资的世界是**多维**的（基本面、大盘、位置、仓位、心态……），多维就一定会撞车。
- 撞车时如果没有优先级，就会陷入无限纠结 → 纠结的代价是**无限的被动**。
- 大多数投资巨亏，本质都是「层次感的冲突」：理性与感性冲突、客观与主观冲突。

## 2. 投资的优先级阶梯（从高到低）

```
① 纪律（止损/仓位规则）   ← 最高优先级，投资的生命线
② 仓位管理 / 维持账户全红
③ 主观认知（我认为它很好） ← 最低优先级，目的只是顺势而为
```

**冲突时的处理原则：永远优先执行更高优先级的那一项。**

### 2.1 纪律 vs 主观认知 → 优先纪律

- 场景：一个好标的不断下跌，跌到你的止损线；你觉得它马上要反弹了。
- 正确动作：**严格止损。**
- 为什么：
  - 纪律是仓位管理的第一优先级，是投资过程的**宪法**；
  - 只要按规矩来，你就是对的；**违背规矩，哪怕最后赚钱了，也是错的**；
  - 单次判断容易陷入**幸存者偏差**；样本足够多（执行十次），长期一定正确——因为跌破止损线本身就说明你对这只股票的认知有问题。

### 2.2 仓位管理 vs 主观认知 → 优先仓位管理

- 场景：账户要维护全红，但有一只微利的标的你主观认为很好，它跌下来就要把利润吐回去、甚至变绿。
- 正确动作：**优先维护账户全红，不断减仓。**
- 为什么：如果它真的是一只好标的，**你没有必要刻意去追成本**——抓住盈利和确定性更关键，**成本没有那么重要**。

## 3. 为什么纪律必须是第一优先级

- 牛市/赛道一定会结束。2015 年、2021 年的消费与新能源，跌起来漫无边际。
- 有纪律的人：到了纪律线就止损，**不可能深套**，牛市结束时至少保住一条命。
- 没纪律的人：因为「持有的标的非常好」一直扛，最后普遍腰斩以上。

> 最考验层次感通透性的问题：**一个你非常看好的好标的，触碰到止损线，该不该止损？**
> 答案：**该，因为纪律有更高优先级。**

## 4. 层次感的长期价值

- 每一次矛盾都是艰难的选择，但**一旦不抉择，就会陷入无限的被动**。
- 侥幸心理有第一次就会有第二次；不从现在养成习惯，最后一定会吃一次大亏。
- 坚持半年以上，你会感谢这样的自己。

## 5. 冲突决策速查（遇到纠结时按顺序问）

1. 这笔操作**违反纪律**了吗？（违反 → 停，先执行纪律）
2. 不处理会不会**破坏账户全红**？（会 → 先减仓）
3. 最后才问：我**主观**怎么看这个标的？
4. 如果主观判断与上面两条冲突 → **放弃主观判断**。

> 记住：主观认知的作用只是「顺势而为」，它没有资格推翻纪律。
