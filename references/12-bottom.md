# 抄底与逃顶：底部是试出来的

> 出处：第 16 课《如何抄底与抄底时机探讨》（2 小时长课）、框架图「大跌后抄底 / 如何选取大盘指数」。

## 1. 第一原则：大盘向下时，不要轻易抄底

- **核心前提**：当下大盘处在**向下局面**（20 日线明晃晃朝下），此时大多数个股均线也朝下 → **不该抄底**。
- 判据：**抄底意愿非常强烈，本身就说明投资还不够成熟**。成熟的投资者面对明晃晃的下跌趋势，首先想到的是「这是左侧，不属于我该交易的区间」。
- **短期投资者应该做右侧**，左侧不是你的交易区间。
- 「心中无顶底」：不要去猜「会跌到哪里」，只根据当下结构判断能不能出手。

## 2. 两个抄底结构（确定性与适用周期不同）

### 结构一：三天不新低（基础版）

- 定义：指数/个股连续 **3 天不再创新低**（**以最低价比较，不是收盘价**）。
- 优点：容易买到较低点位。
- 缺点：**确定性低**，不是高确定性的结构。
- 适用：**超短线**，只博一两天反弹。
- 本质：下跌的**小节点势能**出现收敛。

### 结构二：均线趋势联合朝上（进阶版，推荐）

- 形态演变：
  ```
  下跌结构：20 日线在上、10 日线在中、5 日线在最下（空头排列）
        ↓ 横盘/反弹，均线收敛
  联合结构：5/10/20 收敛黏合
        ↓ 向上发散
  向上结构：5 日线在上、10 日线居中、20 日线在下
  ```
- 出手点：**均线开始联合、或联合后有朝上迹象/已经朝上**。
- 优点：**确定性较高**，买入后获利可能性大。
- 缺点：**买不到最低点**（最低点时均线一定朝下）。
- 适用：**波段投资者**（持股约 1 周到 1 个月），用来抄**优质资产**。
- 本质：**整体性的向下势能**出现收敛。
- 关键认知：**不要追求成本最低，而要追求确定性**——不是成本问题，是能不能盈利的问题。

## 3. 单向 vs 双向叠加（提高确定性的唯一办法）

- 只出现大盘结构、个股仍创新低 → 可以博反弹，但确定性不高。
- 只出现个股结构、大盘仍在下跌 → 确定性也不高。
- **大盘 + 个股同时出现结构（双向叠加）→ 确定性高一分。**
- 逻辑：抄底个股之所以能赚钱，不只因为个股位置低，更因为**大盘反弹时带着向上的势能**，会把个股推上去。

## 4. U 型反弹 vs V 型反弹（决定你要等多久）

- **市场不会 V 型反弹**：20 日线的方向一两天改不过来，趋势要走平需要时间（缓冲带）。
- 所以正常路径是：**下跌 → 震荡 → 均线走平 → 联合 → 朝上**（U 型/圆弧型）。
- 因此：**不要急着抄底**；等出现明确的企稳态势再试探，能帮你避开大量左侧买入的不确定性。
- 除非出现重大宏观变化，否则不要指望 V 型反转。

## 5. 抄底买什么（方向选择）

1. **首选个股均线已经朝上/走进右侧的**——大盘向下时，「两头最起码要站一头」。
   - 大盘高位时资金偏向低位标的；**大盘低位/左侧杀跌时，资金反而偏向高位强势标的**。
2. **不知道选什么 → 选和指数相关的权重**（ETF 会往里压，权重一定跟着反弹）。
3. **前期主线跌透后往往最先反弹**（资金熟悉、逻辑还在）。
4. **底部第一次大涨当天最强的板块**——市场的选择，不要自己猜。
5. 不要买「跌得最多」的，要买「反弹最强」的。

## 6. 逃顶：怎么判断大盘见顶

### 6.1 主线节奏 ≈ 市场节奏

- 主线的形成：**从点到线、再到面**的扩散（少数个股 → 板块 → 全市场赚钱效应）。
- 主线的结束：**从面到线、再到点**的收敛（全面高潮之后只剩个别龙头还在涨）。
- 一旦看到「机会在收敛」→ 这条主线在慢慢走向结束 → 市场情绪随之回落 → 大盘跟着调整。
- 主线之间不是无缝衔接的：**一条主线结束到新主线出现之间，市场会经历一个推倒重来的下跌过程**。

### 6.2 逃顶信号

1. **主线机会收敛**（只剩个别龙头表现，四大材料/其他细分全线调整）。
2. **指数冲高后成交量急速收敛**（量能无法继续放大）。
3. **主线见顶与市场背离**（指数新高、主线不新高）。
4. **当强不强**（大盘涨、主线不涨）。
5. **均线破位**（指数跌破 20 日线并向下发散）。

### 6.3 逃顶动作

- **无差别减仓 / 高度防守**：大盘要跌时，几乎所有股票都会受损（「大盘 > 行业 > 个股」）。
- 会卖的是师父，会买的是徒弟：**卖点常常出现在基本面还在向上时**（股价领先基本面），所以要感受盘面变化，而不是等基本面变坏。
- 减仓顺序：微利标的 → 小亏未止损 → 跟风股 → 最后龙头。
- 逃顶后**不要马上抄回来**，等「三天不新低」或「均线联合朝上」。

## 7. 抄底执行清单

```
① 大盘仍向下 → 只看不动（心中无顶底）
② 出现「三天不新低」→ 可小仓博超短反弹（确定性低）
③ 出现「均线联合朝上」→ 波段级抄底，买优质资产（确定性较高）
④ 大盘与个股双向出现结构 → 加确定性，可提高仓位
⑤ 标的选择：个股右侧 > 指数权重 > 前期主线 > 底部第一次大涨最强板块
⑥ 跌破抄底低点 → 止损，重新等结构
```

> **底部是试出来的，不是判断出来的。**（第 16 课）
