# 主线体系：识别、跟随、见顶

> 出处：第 01 课（建立时机感）、第 07 课（撩妹法则）、第 17 课（如何拥抱投资的确定性）、第 18 课（多卡节奏少选个股）+ 框架图「主线变化的特征 / 应对主线的调整」。

## 1. 为什么先讲主线

- 体系的第一句话是 **先占时机，后占逻辑，最后占位置**。
- 「逻辑」这一层，落到盘面上就是**主线**：一段行情里资金共同认可的方向。
- **市场的大主线不是判断出来的，是走出来的。看见主线，交易主线。**
  → 所以主线研究的目标不是「猜中」，而是「尽早确认 + 确认后敢于重仓」。

## 2. 主线的四个特征（判断是不是主线）

| 特征 | 盘面表现 | 怎么用 |
|---|---|---|
| **持续性** | 不会轻易结束，调整后还能创新高；持续数周~数月 | 允许持股、允许回踩加仓 |
| **波动性** | 跟随试错波动而波动，日内振幅大 | 用「价格脱敏」扛住震荡，不用分钟级信号做决策 |
| **见顶** | 与市场形成背离：指数新高，主线不新高；或主线内部只剩补涨股 | 减仓信号，不是加仓信号 |
| **整体性** | 呈现出整个面上的上涨，板块内多数股票同向 | 单点龙头独舞 → 是题材炒作，不是主线 |

**主线成立的资金门槛**：主线的形成是数万亿以上资金共同推动，不容易轻易结束，也不能轻易判断结束。
→ 反过来说：**没有大资金参与的方向，不能当主线做。**

## 3. 应对主线的调整（三条纪律）

1. **大盘趋势良好 → 考虑做多；大盘趋势不佳 → 坚持防守。** 主线的多头机会建立在市场不出系统性风险的前提上。
2. **不轻易判断主线结束**：主线是数万亿资金推的，结束需要时间，第一次大跌通常不是顶。
3. **主线节奏与大盘节奏基本一致**：用大盘节奏校验主线节奏。大盘走坏时，主线也会跟着歇，别幻想独立行情。

## 4. 主线的时间结构（节奏）

一轮完整的行情，主线大致走三段：

```
启动（先知先觉资金）→ 主升（业绩/逻辑被认可，机构进场）→ 扩散/补涨（散户进场，垃圾股补涨）
```

- **启动段**：只有少数股票动，形态是「个股与大盘双跌后的第一次异动」。
- **主升段**：板块整体走趋势，回踩均线即买点，是本体系的主要利润来源。
- **扩散段**：低位股、垃圾股、跨界股补涨 → **这是风险信号**，不是机会信号（对应「整体性」被破坏）。
- 判断依据：**赚钱效应的扩散方向**。从龙头扩散到二线是健康，从二线扩散到垃圾股是尾声。

## 5. 主线与题材的区别

| | 主线 | 题材 |
|---|---|---|
| 驱动 | 产业趋势 + 业绩兑现（BEAT 法则） | 消息、事件、情绪 |
| 持续时间 | 数月~数年 | 数天~数周 |
| 参与资金 | 机构为主 | 游资为主 |
| 操作方式 | 回踩买、趋势持有、做T降成本 | 打板/低吸，快进快出 |
| 失败形态 | 逻辑被证伪（业绩不及预期） | 情绪退潮，一日游 |

**判断标准**：能不能用 BEAT 法则四要素讲清楚（故事/业绩/共识/标的，见 `13-beat.md`）。讲不清 → 只能当题材做。

## 6. 主线跟踪清单（每周做一次）

- [ ] 本周涨幅前列的板块是谁？连续 2 周在榜吗？（持续性）
- [ ] 板块内上涨家数占比是否 > 50%？（整体性）
- [ ] 龙头是否还在创新高？还是只剩补涨股在动？（见顶）
- [ ] 大盘趋势是良好还是不佳？（决定做多/防守）
- [ ] 主线的催化剂（政策/业绩/事件）在强化还是衰减？
- [ ] 有没有新的、更强的方向在分流资金？（高低切换）

## 7. 常见错误

1. **用判断代替看见**：提前埋伏「可能成为主线」的方向，结果资金不来，时间成本巨大。
2. **把补涨当机会**：主线扩散末端去买低位补涨股，赚小钱亏大钱。
3. **轻易判断主线结束**：第一次大阴线就清仓，错过主升。
4. **无视大盘**：主线再好，大盘系统性下跌时也要防守。

## 8. 主线的扩散与收敛（第 16 课）

- **主线的升起**：从**点**到**线**，再到**面**——少数龙头启动 → 板块跟随 → 全市场赚钱效应扩散。
- **主线的陨落**：从**面**到**线**，再到**点**——全面高潮后，只剩个别龙头还在涨，其他细分全线调整 → **机会在收敛**。
- 判据：当板块里「只有某一个细分/某一只票还在表现」时，就说明**这条主线在慢慢走向结束**，市场情绪随之回落，大盘也会跟着调整。
- **主线节奏 ≈ 市场节奏**：主线是资金的赚钱效应核心、市场情绪的风向标，主线一结束，指数就失去上涨动力。

### 主线之间一定有「推倒重来」

- 一条主线和下一条主线之间**不是无缝衔接**的：中间必然有一个**下跌/调整**的过程（推倒重来）。
- 这个阶段的特点：**没有明确的投资线索**，不要硬找「美妙叙事」，不要高度主动去押下一条主线（那属于交易预期）。
- 实操：推倒重来阶段 = **防守 + 等**；等新主线自己走出来（看见主线，交易主线）。

### 风险期的动作：无差别减仓

- 两条理论叠加：**主线节奏≈市场节奏** + **大盘 > 行业 > 个股**。
- 所以当主线走坏、大盘要调整时，正确动作是**无差别减仓（高度防守）**，而不是只减「看起来弱」的票——大盘一跌，几乎所有股票都受损。
- 配合技术形态判断：指数冲高后**成交量急速收敛**、叠加海外宏观转差 → 果断判断调整。
