# 三大买点及原理（取大盘之势）

> 出处：第 04 课《三大买点及原理》、第 01 课《建立时机感》、第 11 课《均线趋势》交叉验证。

## 1. 原理：个股没有势能，势能来自大盘

- 大盘与个股**同涨同跌**（至少方向一致）。系统性风险时几乎全部下跌；大盘级别上涨时几乎所有个股上涨。
- 少数个股与大盘背离（股灾里也有妖股），但**做投资要站在大概率里**。
- **大盘没有基本面问题**：大盘跌了一定会涨，涨了一定会跌。
  - 所以把对个股涨跌的判断**建立在大盘之上**，判断会理性得多。
  - 个股跌了不必恐慌：如果它是被大盘带下来的，就不是基本面问题。
- **取势**：投资要「明道优术、取势」——取的就是**大盘的势能**。
  - 大盘上涨像春雨滋润万物；大盘杀跌时绝大多数股票跟着杀。
  - 大盘下跌的过程**在蓄积反弹的力量**，个股同步获得这份反弹势能。

## 2. 三大买点

### 买点一：双杀买点（大盘跌 + 个股跌）——最优买点

- 形态：大盘下跌（或大跌）之后，个股同步被带下来。
- 为什么有效：大盘一旦反弹，带强势能，个股跟随反弹。
- **大跌取大势，小跌取小势**：
  - 大盘大跌 → 拿大反弹势能 → 适合建仓/做长；
  - 大盘小跌（小级别双跌）→ 拿小反弹势能 → 适合短线和日内。
- 关键：**核心是大盘必须跌**（只有跌了才有反弹势能）。个股跌不跌无所谓。
- 课程原例：恒生电子 2024/9/23——大盘跌了两年、个股跌了两年，大盘企稳反弹，个股跟着快速反弹。

### 买点二：当弱不弱买点（大盘跌 + 个股不跌）

- 形态：大盘跌了一段，个股**不跌、高位横盘**。
- 很多人看到高位横盘不敢买，但这**同样是买跌**：
  - 大盘下跌时在蓄反弹势能，个股同样获得这份势能；
  - 大盘一反弹，这类股往往**直接新高**（因为它没把跌幅还回去）。
- 原例：恒生电子 2024/10/8–10/14，大盘一路下跌，它几乎不跌，市场一企稳它就创新高。
- 这对应框架里的「**当弱不弱**」——该跌不跌，就是强。

### 买点三：回踩买点（上升趋势中的小调整）

- 形态：大盘（个股）仍处上升趋势，中途出现一波小调整/连续几天回调，但**没有破坏上升趋势**。
- 性质：中等买点，确定性不如双杀，但**赔率开始出来**。
- 对应均线语言：回踩 5/10/20 日均线不破（见 `10-ma-trend.md`）。

> 三类买点的共同点：**都是在「大盘的势能还没有被消耗完」的位置买入**。

## 3. 两大卖点（对称逻辑）

### 卖点一：双涨（大盘涨 + 个股涨）——阶段性卖点

- 大盘上涨会**消耗上涨势能**；势能消耗完，大盘就要回踩蓄力。
- 你在双涨段买入：赚的是「大盘短期趋势延续」的钱，一旦大盘杀跌，个股会把涨的动力**还给市场**。
- 操作：**买在双涨段就只能做短期**，有利润先撤/减仓把利润握住，等下一次双跌再进。

### 卖点二：当强不强（大盘涨 + 个股不涨）——同样是卖点

- 大盘都涨了一大段，个股还在低位不动 → 这股票一定有问题。
- 类比：**青春期长不高，别指望成年期再长高**。该涨的时候不涨，就是弱。
- 所以「买低位补涨股」的逻辑不成立：
  - 大盘上涨势能耗尽后，**高低位个股一样杀跌**；
  - 原例：恒生电子 2025 年 1 月（腰斩后）大盘涨它不涨，大盘反向时它跌得更惨，再次腰斩。

## 4. 两个进阶认知（很重要）

1. **降低对个股 K 线位置的关注**：不要因为「位置低」就买、因为「位置高」就不敢买。
   只要大盘跌了，高低位个股都要被带下来；只要大盘涨，高低位个股都能获得上涨势能。**位置的高低只在形态层面有意义，势能层面没有意义**（形态层面见 `09-wave-pattern.md`）。
2. **放大视角，不要被一两天的背离带走**：判断大盘与个股的背离，**至少用周线级别**看，不要因为一天没涨就怀疑。
   不需要非常精确，按这个感觉执行，确定性会慢慢提高。

## 5. 买点决策流程（实战顺序）

```
① 看大盘：处在上涨/下跌/震荡的哪个阶段？势能是积累还是消耗？
② 判断买入位置属于哪一类：
   双杀（最优） > 当弱不弱（同样好） > 趋势中回踩（中等） > 双涨追高（最次，只能短）
③ 个股层面：主线方向 + 图形/均线确认（09/10 文件）
④ 仓位：先试仓，盈利再加（06-pickup-law）
⑤ 止损：定线 -15% / 定量止损额（04-stop-loss）
```

## 6. 常见错误清单

| 错误 | 为什么错 | 正确做法 |
|---|---|---|
| 双涨之后追高做实长期 | 势能已被消耗，赚的是趋势延续的钱 | 只能做短期，有利润先撤 |
| 大盘涨时买低位补涨股 | 大盘无势能，高低位一起杀 | 买势能，不买位置 |
| 只看个股 K 线找买卖点 | 个股没有势能，只有跟涨跟跌 | 大盘定势能，个股定形态 |
| 大盘跌就恐慌割肉 | 个股只是被带下来，非基本面问题 | 等大盘企稳/反弹取势 |
| 因一两天背离就否定个股 | 视角太短，噪音太大 | 至少用周线级别判断 |
